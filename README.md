# football-pose-estimation-mediapipe
A 2D-pose estimation model built using Mediapipe to analyse 5 shots from Dominik Szoboszlai to analyze. I applied MediaPipe’s pose estimation model to detect anatomical landmarks and calculate the knee joint angle at the moment of ball contact. An evaluation of elite level shooting technique.

## Overview

The system detects body landmarks from video footage and calculates joint angles during the shooting motion.

This allows quantitative biomechanical analysis of elite football players.

## Features

- Pose detection using MediaPipe 
- Joint angle calculation (knee angle)
- Video processing with OpenCV
- Landmark extraction and analysis
- Annotated output video
